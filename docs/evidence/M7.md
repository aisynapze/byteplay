## CI defect and narrow correction
Run #41006463850 had standard and Chromium jobs pass but one race-enabled local-seed 100 Mbps subtest stalled for 40 seconds waiting for a peer; it returned mismatched empty range data. On subsequent runs the identical test passed. Introduced a **test-only** 500ms loopback peer reconnection check while no active peer exists, preserving strict HTTP206, exact byte range, and incomplete torrent assertions. Run #41006976266 passed after the change; latest #41007070375 also passed. This is observed test instability, not proof of a production swarm regression.
